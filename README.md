# 高配当株 分析＆魅力度チェッカー (Dividend Stock Analyzer)

株式番号（4桁の証券コード）または会社名を入力するだけで、企業の過去の決算・配当推移・利回り・財務健全性を即座に取得・分析し、**高配当株としての投資魅力度（投資適格性）を100点満点で判定・視覚化するWebアプリケーション**です。

---

## 🌟 主な機能

1. **柔軟な検索入力**:
   - **株式番号（4桁コード）**: `8058`, `7203`, `9433`, `2914` など
   - **会社名（日本語 / 英語）**: `三菱商事`, `トヨタ`, `任天堂`, `Apple`, `Coca-Cola` など
   - **米国株ティッカー**: `AAPL`, `KO`, `MSFT`, `NVDA` など
2. **多角的スコアリング（100点満点）＆ ランク判定**:
   - **ランク S（85点以上）**: 非常に魅力的（投資適格・トップクラス）
   - **ランク A（70〜84点）**: 魅力的（良好な高配当株）
   - **ランク B（50〜69点）**: 平均的・要警戒（一部リスクあり）
   - **ランク C（50点未満）**: 投資非推奨（低利回り・減配リスク等）
3. **診断総評とアラート機能**:
   - 企業の評価ポイント（強み・メリット）
   - 投資前に警戒すべきリスク要因（減配リスク、タコ足配当、赤字転落、CFマイナス等）
4. **充実したグラフ可視化**:
   - 過去の年間配当金推移（増配/維持/減配の色分け表示）
   - 業績推移（売上高・営業利益・当期純利益・EPS）
   - 財務・キャッシュフロー推移（自己資本比率、営業CF、フリーCF）
   - 6大指標のレーダーチャート

## 📊 評価ロジック（6大指標の配点基準）

| 指標 | 配点 | 評価の着眼点 | 理想水準 |
| :--- | :---: | :--- | :--- |
| **① 配当利回り** | 20点 | 予想年間利回りの高さ | 4.0%以上（満点）、3.5%以上（高評価） |
| **② 減配リスク (配当性向)** | 20点 | 利益に対する配当金の割合 | 30%〜60%（健全）。80%超は警戒、100%超（タコ足配当）は大幅減点 |
| **③ 配当継続力・増配実績** | 20点 | 過去数年間の非減配・連続増配実績 | 過去5年以上減配なし、連続増配・累進配当 |
| **④ 業績・収益の安定性** | 15点 | 過去決算の黒字継続、売上・利益の成長性 | 継続黒字、売上・営業利益が右肩上がり成長 |
| **⑤ 財務健全性** | 15点 | 企業の安全度と資金創出力 | 自己資本比率 50%以上、直近フリーCFがプラス |
| **⑥ 割安度** | 10点 | 株価の割安性（PER・PBR） | PER 15倍以下、PBR 1.0倍以下 |

> ※ 評価基準や配点は [config.py](file:///C:/Users/admin/OneDrive/Desktop/株式調査/config.py) から自由にカスタマイズ可能です。
